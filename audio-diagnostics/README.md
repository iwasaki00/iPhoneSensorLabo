# 音声入出力確認ツール

iPhoneに接続したマイク付きイヤホン、ヘッドホン、ヘッドセットの音声入力と出力、音量、波形、遅延、Web Audio APIの対応状況を確認する静的Webアプリです。音声加工やピッチ変更は行いません。

## 起動方法

リポジトリのルートで `node server.js` を実行し、PCでは `http://localhost:8123/audio-diagnostics/` を開きます。iPhoneでマイクを利用するには、原則としてHTTPSで公開してください。マイク取得APIは安全なコンテキストでのみ利用できるためです。

## GitHub Pagesで公開する

1. GitHubリポジトリの Settings → Pages を開きます。
2. Deploy from a branch を選び、公開ブランチと `/ (root)` を指定します。
3. 公開URLの `/audio-diagnostics/` をiPhone Safariで開きます。

## iPhone Safariでのマイク許可

「マイクを開始」を押し、Safariの確認画面で許可します。拒否した場合はアドレスバーのページ設定、またはiPhoneの「設定」→「Safari」→「マイク」を確認してください。許可後にデバイス一覧を再取得します。

## 実機確認手順

### パターン1：何も接続しない

1. iPhone Safariでアプリを開きます。
2. マイクを開始します。
3. 話して音量バーが動くか確認します。
4. テスト音を再生します。
5. iPhone本体スピーカーから聞こえるか確認し、回答ボタンを押します。
6. モニター出力を低音量でONにします。

### パターン2：有線マイク付きイヤホン

1. 有線イヤホンを接続します。
2. デバイス情報を再取得します。
3. マイク名やデバイス一覧の変化を確認します。
4. マイクに話して音量バーを確認します。
5. テスト音がどこから聞こえるか確認して回答します。
6. モニター出力を低音量で確認します。

### パターン3：Bluetoothヘッドセット

1. Bluetoothヘッドセットを接続します。
2. Safariを開き直します。
3. デバイス情報を再取得します。
4. マイク入力がBluetooth側か、実際に話して確認します。
5. テスト音の出力先を確認して回答します。
6. モニター出力を低音量で確認します。

## 注意と既知の制限

- iOSが音声出力先を自動決定する場合があります。Webアプリは実際の出力先を完全には取得・指定できず、画面上でも推測による断定はしません。
- iPhone Safariではデバイス名、`audiooutput`、遅延、`devicechange`などが取得できない場合があります。
- モニター出力は遅延します。表示する合計遅延はAPI値からの推定であり実測値ではありません。
- 本体スピーカーでモニターするとハウリングする可能性があります。イヤホンを使用し、低音量から試してください。
- Safari、Chrome、EdgeなどWeb Audio APIとMediaDevices APIを備えた最新版ブラウザを対象とします。iOS上の各ブラウザにはSafariと同様の制約があります。
