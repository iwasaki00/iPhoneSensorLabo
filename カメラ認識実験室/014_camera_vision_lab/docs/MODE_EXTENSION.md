# モード追加方針

`RecognitionMode` の `id`、`runtime`、`initialize()`、`infer()`、`dispose()` を実装し、モード固有の依存を `src/modes/` に閉じ込めます。v0.1.0は物体の矩形結果を共通形式としています。姿勢のランドマークやセグメンテーションを追加する際は、結果を識別子付きunionへ拡張し、描画アダプターを分けます。

モードの切替は「スケジューラー停止→世代ID更新→進行中結果を無視→旧モードdispose→新モードinitialize→再開」の順で行います。Worker内の処理はWorker終了で解放し、メインスレッドのTasksはcloseします。モード切替時に旧モデルを常駐させません。

各モードにモデル・ライブラリの固定バージョン、ライセンス、同一サイト配信パス、SHA-256、互換方式を用意します。モデルを同時に複数読み込む設計は採用しません。推論完了後に次の予約を入れ、非同期推論中の再入を禁止します。映像描画は独立のrAF、表示FPSは映像フレーム通知、認識FPSは結果完了通知で計測します。

次バージョン候補はv0.1.1としてiPhone実測を反映した認識間隔・解析長辺の初期値調整、回転・復帰の安定性改善です。その後、需要に応じて顔検出や手のランドマークを追加します。実装が完了するまではモード選択ボタンを表示しません。ゲーム機能は本実験ツールの範囲外です。
