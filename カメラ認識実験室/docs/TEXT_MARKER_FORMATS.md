# TEXT & MARKER LAB 対応形式

Version 0.6.0。ライブラリの対応範囲とPCで今回確認した範囲を区別します。iPhone実機は未確認です。

| 実験 | 実装・対応範囲 | 今回のPC確認 |
| --- | --- | --- |
| OCR | Tesseract LSTM、日本語 `jpn`・英語 `eng`・混在 `jpn+eng`、数字。文字・行の枠と信頼度 | 合成した横書き日英数字、グレー前処理、編集・コピー。日本語の文字間に空白が入る例あり |
| コード | ZXing MultiFormatReader。QR、EAN-13/JAN、EAN-8、Code 128、UPC-A/E、Code 39/93、ITF、Codabar、Data Matrix、Aztec、PDF417など | QR・EAN-13・EAN-8・Code 128の合成画像。その他はライブラリ対応で実物未確認 |
| 登録画像 | OpenCV ORB、Hamming kNN、RANSAC平面射影 | 模様画像を約17度回転・0.9倍縮小して照合、四隅・内点数、合成画像 |
| マーカー | js-aruco2 ARUCO_MIP_36h12、6×6ビット、250種類（ID 0〜249） | 生成ID 7・11、同一ID複数検出、消失・復帰、PNG保存 |
| 平面合成 | 文字・四角・円・画像、マーカーまたは登録画像の四隅 | 比較表示・各種合成、回転追従。印刷実物・強い遠近は未確認 |

コードは1回1件の読取です。同一形式＋内容の履歴はメモリ内最大100件、最終検出から10秒で失効します。位置はエンジンの検出点であり、必ずしも四隅ではありません。通常のQR検出に失敗した場合は単独・正面QRの補助読取を試し、黒画素範囲の近似位置を表示します。

登録画像の反復模様・無地・低コントラスト・画面外・大きな遠近変形では棄却または誤一致が起こります。ArUco互換を名乗る他辞書（DICT_4X4等）は対象外です。角度は画像平面上の値であり、カメラ校正・3D姿勢推定は実装していません。
