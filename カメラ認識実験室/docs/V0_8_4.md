# v0.8.4 — HIDE SPOT FINDER / 隠れ場所の候補

## 操作

親メニュー→カメラ認識実験室→奥行き認識→D. かくれんぼ。写真を解析して「候補を探す」を押す。探索終了だけでは配置を変えない。最大3件の候補から選び、写真上で見え方を確認し、必要ならドラッグ・奥行きで微調整する。「元の配置に戻す」は、その探索結果で最初の候補を選ぶ直前の位置・奥行きへ戻す。復帰後の再選択では、その直前の配置を新たに記憶する。

大きさは従来と同じ写真短辺の35%。画質・輪郭補正・遮蔽の初期値を変更しない。手動配置→端末を渡す→探す→発見→隠し直す、はそのまま使える。候補なしの場合は手動で置くか別写真を使う。候補選択、探索、復帰、ドラッグ、隠し直しでAIを再実行しない。

## 調査と再利用

- `DepthPanel`の表示写真座標・ロボット素材・`occlusionAlpha`のギザギザ軽減・`refineContour`の局所補正を再利用。
- `hideFrame`に従来の本体描画を抽出。アンテナ装飾と透明余白を除いた同じalphaを、通常描画と候補の最終確認に使用する。
- 既存`visibility`の開始判定を粗判定・最終判定・実際の開始で共用。可視率12〜65%、画像内に全体が収まり、最大連結部分36 CSS px²以上、幅・高さ各6 CSS px以上が必要。
- 探すときは従来の開始時固定マスクと`visibleHit`を使う。候補専用の正解範囲は作らない。元の深度値、色分け、2点比較は変更しない。
- Worker・モデル・WASM・カメラ・座標変換・既存認識エンジン・ARカードには処理変更なし。追加依存なし。

## 探索方法・上限

1. 深度の表示用マップを長辺128px以下に縮小して粗判定。写真自体やAIの入力解像度は変更しない。ロボット本体は48pxのalphaで近似する。
2. 13×13の位置格子を確認。本体の深度分布の10〜90百分位に、写真全体の深度範囲に対して6%以上の差がある場所だけを試す。平坦な領域は除く。これは意味的な物体境界の認識ではないため、傾斜した面にも反応しうる。
3. その場所の28／50／70百分位の深度を、既存スライダーと同じ整数0〜100へ変換して試す。最大480試行。18試行ごとにイベントループへ制御を返す。
4. 開始判定を通り、可視画素中の最大連結部分が60%以上の配置を残す。最大連結部分の割合を主に評価し、可視率35%付近を優先。近い配置を整理して最大16件を残す。
5. 16件それぞれを表示解像度で実際の本体描画→既存遮蔽→必要なら現在の輪郭補正→既存開始判定で確認。1件ごとに制御を返す。画面上で小さすぎる部分や画像外配置も落とす。粗判定だけの結果は表示しない。
6. 最終順位では既知のロボット素材の頭部にまとまって見える画素も加点する。写真の顔・物体の意味認識は行わない。中心距離がロボット幅の65%未満の候補をまとめ、最大3件に絞る。1〜2件ならその件数、0件なら案内のみ。数を埋める補充処理はない。

試行数は固定上限で、写真全体の最適解を保証しない。実寸マスクの1件の処理は同期処理であり、大きな表示バッファや低速端末では一時的に操作応答が遅れる可能性がある。3MP上限は従来どおり。iPhoneでの最大負荷は未測定。

## 状態管理・プライバシー

探索中のボタンを無効にし、メソッド側にも重複防止を設ける。写真差替え、再解析開始・完了、輪郭補正切替、実験変更、モード終了、端末を渡す段階への移行で世代番号を更新し、候補・復帰先を破棄する。分割処理後は世代・写真のマップ同一性・編集段階を検査し、古い結果を公開しない。

探索中に手動で動かした配置は探索完了で上書きしない。復帰先は探索開始時ではなく最初の候補選択時に取得する。探す・手渡し画面では候補DOMも消し、答えのUIを表示しない。

画像・深度・候補・復帰先はメモリ内のみ。通信・localStorage・実験記録への候補位置の保存は追加しない。開発検証のPNG／JSONは公開写真を使って明示的に出力したもので、アプリの自動保存ではない。

### 採用しやすさ・不自然さ

- [coffee・候補1 OFF](depth-validation/v0.8.4-coffee-off-1.png): 頭と目がまとまって見え、押す場所を見つけやすい。一方、皿の面の途中で隠れており、自然な物陰として成功とはいえない。手動の奥行き・位置調整が必要。
- [coffee・候補2 OFF](depth-validation/v0.8.4-coffee-off-2.png): カップ内に顔が現れる配置。頭部の可視性は良いが、内容物の途中で切れる深度推定が不自然。
- [coffee・候補3 OFF](depth-validation/v0.8.4-coffee-off-3.png): 木の面の途中で切れる明確な不自然例。局所の深度差だけでは本当の遮蔽物と傾斜を区別できない。サンプル専用の除外座標は入れていない。
- [astronaut・候補1 OFF](depth-validation/v0.8.4-astronaut-off-1.png): 頭部がまとまって残り、手前のストラップによる部分遮蔽を確認できる。ただし下端も衣服の面で切れるため、そのまま自然な配置とはいえない。
- [astronaut・候補2 OFF](depth-validation/v0.8.4-astronaut-off-2.png)／[候補3 OFF](depth-validation/v0.8.4-astronaut-off-3.png): 細い残りや衣服での不自然な切れがある。最大連結部分の基準で小断片を減点しても完全には除去できない。

補正ONの各候補も `depth-validation/v0.8.4-{coffee,astronaut}-on-{1,2,3}.png` に残す。ONでも広い前後誤りは直らず、自然さを保証しない。画面上の可視性を満たす配置例の提案であり、意味的な物体やゲームの正解をAIが判断したものではない。

coffeeは既存Rachel MichettiのCC0サンプル（[許諾](../public/samples/coffee-LICENSE.txt)）。astronautはNASAのEileen Collins写真、scikit-image v0.25.2収録のpublic-domain素材。出典・ハッシュ・取得手順は [v0.8.3資料](V0_8_3.md#実写真の出典と再現) と同じ。NASA写真のPNGは検証用の加工・合成で、NASAの制作・承認を示さない。追加写真原本はGit対象外の検証フォルダのみで、distには増やさない。
