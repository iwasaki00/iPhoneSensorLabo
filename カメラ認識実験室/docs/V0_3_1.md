# v0.3.1 — PERFORMANCE & STABILITY

実装・PC確認日: 2026-11-12。commit・push・公開は実施していません。iPhone実機は未確認です。

## 調査と変更

- 既存の `inFlight`、完了後タイマー、カメラ／モード／結果の世代ID、`ModeSession` の初期化キュー、Worker終了、Tasksのclose、モデルfetchのabortは実装済み。その仕組みを維持しました。新しいカメラ取得ループやWorkerを重複追加していません。
- 領域認識だけマスクが無期限に有効で、解析時の静止フレームを表示していました。撮影タイムスタンプからの期限判定と、推論から独立したライブ合成へ変更しました。
- マスクの空間平滑化は既存。時系列補正と孤立ノイズ除去だけを追加しました。
- FPSは実測通知から算出済みですが、2秒窓では2秒以上かかる推論を表示できませんでした。映像・描画は2秒窓、認識だけ10秒窓に変更しました。
- 設定は既存のv2／segmentation.v1キーを維持。新しい項目に初期値を補い、実験記録だけを別キーに保存します。

## 自動負荷調整

領域認識の初期値は自動。推論呼出しから転送・マスク補正・初回合成の完了までの実測経過時間を `0.75×前回平均 + 0.25×今回時間` で平滑化します。初回は今回値です。次の待機は `平均×1.5` を50ms単位で切り上げ、選択した基準待機以上・2000ms以下に制限します。実測経過の平均が200msを超えると「高負荷」を表示します。CPU使用率・電池消費量を表すものではありません。

手動待機は100/200/500/1000ms、取得・合成長辺は160/256/384px。自動で解像度を下げません。モデル内部入力は両モデルとも256×256のままです。設定リセットは負荷・品質だけを初期値へ戻し、従来の色・動体・輪郭設定を保持します。

常に前の解析が終了してから待機し、次の最新フレームを取得します。進行中に新たな解析フレームを積みません。モード／モデル変更時は旧エンジンをdisposeし、旧結果を世代IDで捨てます。解析サイズ変更でも結果世代を更新し、旧サイズの結果を捨てます。

## マスクとライブ合成

- 平滑化ON/OFF、時系列強度0〜100、従来の境界補正0〜100。前後のカテゴリが同じ・確率差0.25未満・対応する元画素のRGB各成分差24未満の画素だけ過去の確率を混ぜます。過去の重みは最大0.65です。
- 上下左右4画素がすべて同じ別カテゴリに囲まれた孤立画素だけを補正します（強度30以上）。細い境界を全体的に削る処理はしません。画像外周1pxは補正対象外です。
- モデル・サイズ・カテゴリの変化、色変化、長い更新間隔では古い確率を混ぜません。履歴の最大間隔は1200msか設定期限の短い方。停止／切替／期限切れで履歴を解放します。高速動作での遅れを完全に消す手法ではありません。
- マスク期限は撮影時点から初期2000ms、UIは500/1000/2000/5000ms。既に期限を過ぎた推論結果は表示しません。途中で更新が止まった場合も期限後に元映像へ戻します。
- BEFOREはライブ映像、加工は最大15 FPS。新しい推論がなくても直近の有効マスクと新しい映像で合成します。マスクの境界計算・占有率は結果や加工設定が変わるまでキャッシュします。左右比較は同じ位置変換・鏡像処理を使いますが、同時刻の画素比較ではありません。
- メインCPU互換方式では同期推論中にUIが止まる場合があります。Worker方式でも合成はメインスレッドで行います。描画FPSは実際の描画回数で、加工の更新FPSとは異なります。
- 既存MediaPipe処理は返却結果が有効な間に必要な配列をコピーし、finallyで結果をcloseします。Workerは所有する2バッファだけを転送し、ImageBitmapもfinallyでclose。SDKマスクや借用ビューはUIに保持しません。この既存処理は再実装せず、解放後にネイティブ配列を無効化するテストでコピーの独立性を確認しました。

## 実験記録

手動で現在値を記録。日時（ISO UTC）、Version、モード・サブモード、モデル、解析解像度、描画／推論FPS、平均／最大推論ms、実効待機、負荷調整方式、実行方式、UA、言語、platform、取得可能な論理コア数を保存します。平均・最大は直近最大120回。未計測値はnull。CPU使用率・物理メモリ・電池消費量は記録しません。

`camera-vision-lab.experiments.v1` に最大50件。上限超過は最古から削除し、最新10件を残す／全削除も可能です。読み書きと書出しは明示したメタデータの許可リストを使用し、映像・画像・背景画像名を含めません。破損記録は無視。保存拒否・容量不足時はタブ内で保持して書き出せます。JSONとUTF-8 BOM付きCSVに対応し、CSVの引用符・数式開始文字を処理します。保存先はブラウザと端末のダウンロード操作に依存します。
