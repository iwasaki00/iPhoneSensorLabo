# 風景認識の対応カテゴリ

公式 `@tensorflow-models/deeplab@0.2.2` のラベル順に対応します。ADE20Kは背景・未分類を含む151出力、Cityscapesは19出力です。IDを保持し、同じ英語名が複数回現れる場合も別IDとして扱います。主要カテゴリを日本語表示し、それ以外は配布元の英語名を維持します。

Cityscapesは空・道路・歩道・建物・植物・壁等に対応しますが、床・天井・家具を個別分類する出力はありません。壁の出力があっても室内での精度を保証しません。未対応と、対応しているが今回検出されなかった状態を区別してください。

配色は公式定義が基本です。ただしADE20Kの道路（ID 7）と高層建物（ID 49）が同じ灰色のため、表示上はID 49だけ白へ変更し、151出力すべてを異なる色で区別しています。ラベルID・推論結果は変更していません。
