| `npm test` | 8件成功 | 日本語変換、閾値境界、英語維持、不正結果、contain座標と鏡像、エラー案内、カメラ開始停止、遅着Stream解放、再生失敗と旧セッション競合、実測FPS |

最後のブラウザテストは `npx playwright test -g 'Workerの推論失敗'` に絞って追加実施しました。全ブラウザ4件を変更のたびに繰り返す運用にはしていません。単体テスト8件と最終ビルドも成功しています。

初期検証ではWorkerのバンドルを `.cjs` のまま配信すると互換方式が選択されました。classic Worker用配布物を `.js` へ変更した後、診断表示と実推論でWorker方式を確認しました。また、PC模擬カメラの初回開始でTrack終了エラーが発生した試行がありました。最終検証では取得Trackを記録し、開始・停止・再開・切替が完了しています。PCの模擬デバイスでの成功をiPhoneカメラの安定性や認識精度の確認とは扱いません。

## 未確認事項

- iPhone Safariでの権限UI、実カメラの方向選択、鏡像・回転、画面ロック・復帰
- iPhoneでのWorker / ImageBitmap / WASM SIMDの実際の組合せ、CPU互換方式の操作応答
- 実物に対する検出精度・位置の一致、暗所や逆光、物体の遮蔽
- iPhone上の持続FPS、発熱、電池消費、メモリ使用量、5分以上の連続動作
- iPhoneでの不要なダブルタップ拡大抑制の挙動
- 実際のHTTPSローカル配信とGitHub Pages配信。今回どちらも外部公開していません

アプリが示すFPSと推論msはその実行時の実測値です。保存したスクリーンショットの値をiPhoneの性能値として使わないでください。カメラ表示FPS API非対応時は数値を補間しません。

静的配布物は `dist/`（約24.5MB、SIMD/非SIMD両方のWASMとライセンスを含む）。`dist/index.html` をファイルとして直接開かず、HTTP(S)サーバー経由で起動してください。起動したテスト用プレビューサーバーはテスト終了時に停止しています。

初回実装時にはGit初期化・commit・push・公開、既存アプリの変更は実施していません。
