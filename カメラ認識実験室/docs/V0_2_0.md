# Version 0.2.0 — COLOR & MOTION LAB

## 実装

既存の統合済み「カメラ認識実験室」直下を更新しました。旧 `014_camera_vision_lab/` は作成していません。Vite + TypeScript、静的配布の `dist/`、親メニューのリンク、物体認識の固定ライブラリ・モデル・WASMと配布条件を維持しています。ソース・設定はLFとし、上流実行アセットのバイト列はSHA-256で保持しています。

| モード | 手法 | 結果と操作 |
| --- | --- | --- |
| 物体認識 | MediaPipe Tasks Vision 0.10.21 / EfficientDet-Lite0 int8 revision 1 | 日本語名・位置・信頼度・件数、閾値、認識ON/OFF、Worker/CPU互換方式を維持 |
| 色認識 | HSV範囲抽出・8近傍連結領域・重心の近傍対応付け | タップ選色、H/S/V許容幅、複数領域、ID・中心・面積・軌跡、微小ノイズ除外 |
| 動体検出 | 固定背景の輝度差分・連結領域・重心追跡 | 背景再取得、感度、矢印、表示px/s、軌跡、約1.2秒の静止判定 |
| 輪郭・図形認識 | RGB各成分の3×3平滑化とSobel・連結領域・凸包・頂点削減・円形度・主軸 | 直線・円形・三角形・四角形・未分類、中心・近似面積・傾き、感度・ノイズ除外 |

新規の依存ライブラリ・有料API・AIモデルはありません。OpenCV.jsは今回必要な演算と長辺320pxの処理範囲に対して追加配布・初期化・リソース管理が大きいため採用していません。モデル・WASMは物体認識を選んだときだけ取得します。新モードは専用JS Worker、非対応時は通常のメインスレッド画像処理で動作します。

## 共通動作

- モードは1つだけ実行し、切替時は旧Worker・モデル・背景・追跡履歴を解放。カメラのMediaStreamは維持。
- 非同期処理完了後に次を予約し、解析は多重起動しない。物体認識の解析長辺は従来設定、新モードは最大320px・24領域。
- 表示方法は通常、BEFORE、AFTER、左右比較。表示変更はモードを再初期化しない。前面反転とタップ逆変換も共通のcontain座標を使用。
- 認識エラーはカメラと切り離し、映像を継続。認識再試行または別モードで復旧可能。カメラ自体のエラーは停止・再試行。
- 設定のみlocalStorageへ保存。画像・背景・軌跡の永続保存や外部送信は行わない。
- 映像FPS、描画FPS、認識FPS、処理msを実測。処理msは画素演算または推論のみで、取得・転送・描画・待機を含まない。

## 制約・実機で必要な確認

- iPhone Safari実機は未確認です。[実機確認手順](IPHONE_CHECKLIST.md)に従ってHTTPSで親メニューから起動してください。
- 色は照明・露出・ホワイトバランスに影響されます。同色領域が接触すると1領域になります。
- 動体検出は固定カメラ用。照明変化や手ぶれ、背景に最初からあった物の移動による元位置の差分も検出します。物理速度は計測しません。
- 重心の近傍対応付けなので、領域の交差・結合・急激な移動・1秒超の解析間隔でIDが切り替わる場合があります。静止は重心変化に基づく判定です。
- 図形は凸包を使う近似です。凹形の実面積や穴の面積は計測しません。円は傾きなし、直線は面積なし。重なり・画面端・弱い境界などは未分類／未検出になり得ます。
- BEFOREはライブ映像、AFTERは直近の解析結果のため時間差があります。比較幅の変化により表示px/sの値は変わります。解析座標の中心・面積は表示幅で変わりません。
- CPU互換方式はUIを一時的に止める場合があります。停止・切替時のTasks初期化は完了待ちになる場合があります。
- iPhoneでの前面座標・回転・タブ復帰、Worker可否、ダブルタップ拡大抑制、5分の持続性能・発熱・電池は未確認です。
