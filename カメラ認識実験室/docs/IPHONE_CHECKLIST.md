## v0.3.0 SEGMENTATION LABの追加確認

カメラ実機とiPhone Safariでの以下の項目は未確認です。HTTPS配信と親メニューの起動手順は従来と同じです。

1. 「領域認識」→「人物」で起動し、SelfieSegmenterの取得状態とロード時間を確認。元映像・強調・人物だけ・背景だけ・マスクを切り替える。
2. 髪・顔・肩・腕・指の境界、人物の移動、逆光・暗所・複雑な背景で確認し、境界補正0/35/100の差を記録。個々の指を別カテゴリとして認識する機能はない。
3. 「部位」に切り替え、SelfieMulticlassの読み込み後に背景・髪・体の肌・顔の肌・服・その他の色凡例、検出状態、占有率、モデル名を確認。目・口・指などは未対応の表示を確認。
4. 「背景加工」のぼかし・単色・画像・減光を試す。ぼかし強度と境界補正を調整し、人物領域が保たれるか確認。端末内のPNG/JPEG等を選択し、縦横比が異なる画像も確認する。画像は中央coverで配置され、画面外は切り取られる。
5. ローカル背景画像を「解放」し、未選択の案内に戻ることを確認。ページ再読込で画像は残らず、画像選択の設定だけが復元されることを確認。
6. 「部分加工」で髪・服の色変更を試し、明暗・質感の残り方と境界の漏れを確認。髪・服以外の対応部位で対象のみ／対象以外のモノクロを試す。部位がない場合は加工せず理由が出ることを確認。
7. 通常／BEFORE／AFTER／左右比較と前面／背面を組み合わせ、同じ解析フレームの元映像と加工位置が一致することを確認。前面は両方を同じ方向へ反転する。
8. 人物↔背景加工、部位↔部分加工では不要な再ロードがなく、人物↔部位では必要なモデルだけが読み込まれることをWebインスペクタで確認。映像や背景画像の送信・外部ストレージ保存がないことも確認。
9. 長辺160/256/384px、間隔100/200/500/1000msで試す。モデル入力は256×256のままである点に注意。描画FPS・推論FPS、平均／最大推論時間、加工時間、ロード時間、発熱・電池・メモリを各モード5分程度記録。
10. モデル読み込み中や推論中に停止し、カメラ使用表示が消えることを確認。再起動、素早いモード切替、タブ移動／復帰、他の4モードへの復帰を確認。読み込み失敗でも映像が継続し、「認識を再試行」で復旧できることを確認。
11. v0.2.0で保存した色・感度・比較設定が残っていることを確認。領域用の設定を変えても旧設定が消えないことを確認。

初回ロードのネットワーク時間と、キャッシュがある状態のロード時間は分けて記録してください。PCの測定値をiPhoneの欄に転記しないでください。

## v0.2.0 COLOR & MOTION LABの追加確認

HTTPS配信を準備して親メニューの「カメラ認識実験室」を開いてから実施します。

1. 物体認識で起動・前後切替・停止・再起動と、名前・信頼度・閾値・件数を確認。
2. カメラ動作中に色認識へ切り替え、カメラ使用表示と映像が途切れないことを確認。赤・青などの物体をタップしてHSV許容幅を変え、同色の複数領域、中心、面積、ID・軌跡、ノイズ除外を確認。
3. 通常・BEFORE・AFTER・左右比較を切り替え、同じ物体と枠の位置が一致することを確認。前面カメラでタップした色と領域が一致することも確認。AFTERは結果だけで、色選択は表示範囲内の元映像位置に対応する。
4. iPhoneを固定し動体検出へ切り替え、「背景基準を再取得」を押す。物を動かし、強調領域・矢印・表示px/s・軌跡を確認。物を約1.2秒静止させ、検出データの「静止」を確認。カメラ移動と照明変化による誤検出も記録。
5. 輪郭／図形認識へ切り替え、白黒や鮮明な色の円・三角形・四角形・直線、凹形、微小ノイズで確認。中心・近似面積・傾き、円の傾き「—」、未分類の輪郭の表示を確認。
6. 感度、HSV許容幅、比較表示、モードを変更して停止・ページ再読込。設定が復元され、カメラは勝手に起動しないことを確認。
7. 素早いモード切替、認識ON/OFF、物体認識への復帰、タブ移動と復帰を確認。認識エラー時も映像が継続し、「認識を再試行」や別モードで復旧できることを確認。
8. 各モード5分程度で映像FPS・描画FPS・認識FPS・処理ms、発熱、バッテリーを記録。PCの数値で補わない。Safari実機のWorker／互換方式を診断から転記。

スマートフォンのカメラ自体が動く条件や物理速度計測は今回の対象外です。日本語キーボード不要の選択・スライダー操作ですが、ダブルタップ拡大抑制と画面回転は実機で確認してください。

## ローカルHTTPSの準備（公開不要）

1. `npm ci`、`npm run assets`、`npm run build` をPCで実行する。
2. PCの `dist/` を静的サーバーで配信する。Caddy等を使い、PCのLAN IPまたはローカルホスト名に対してHTTPSを構成する。証明書にはアクセス先IP/ホスト名のSANが必要。
3. 信頼できるローカルCAで発行した証明書を使用する。iPhoneにCA証明書をインストールし、「設定 → 一般 → 情報 → 証明書信頼設定」で信頼する。秘密鍵はiPhoneへコピーしない。証明書警告を無視しただけの接続では確認しない。
4. PCとiPhoneを同一LANへ接続し、PCのファイアウォールで使用ポートを許可する。Safariで `https://<PCのLAN IPまたはホスト名>:<ポート>/` を開く。
5. 診断情報の「安全な接続: true」「カメラAPI: true」を確認する。HTTPのLAN URLやiPhone上のlocalhostはPCへ接続する方法にはならない。

サーバーや証明書は本プロジェクトには自動導入しません。将来のGitHub Pages利用時は配信URLのHTTPSを利用できますが、今回push・公開はしていません。

## v0.3.1の重点確認（iPhone実機は未確認）

1. 信頼されたHTTPSで親メニューを開き、「カメラ認識実験室」を選ぶ。v0.3.1を確認し、下部の起動ボタンで許可する。
2. 領域認識→人物→部位と切り替え、「詳細設定」の自動／手動を比較する。負荷表示・実際の待機時間・平均／最大推論msを確認。解像度が自動で変わらないことを確認する。
3. 手動1000msでもBEFOREと加工映像が動き続けることを確認する。通常・BEFORE・AFTER・左右比較と、前面／背面で鏡像・マスク位置を確認する。左右は同時刻の静止画比較ではない。
4. 平滑化ON/OFF・時系列補正・境界補正を比較。髪、服、指、高速な動作、照明変化でちらつき・残像を記録する。期限500msでは遅い推論結果が表示されない場合がある。
5. 物体→人物→部位→色→動体を繰り返し、旧マスクが残らずカメラが維持されることを確認。停止→再起動・前後切替・認識OFF/ON・背景移行も確認する。
6. 「実験記録」を開き計測値を保存し、再読込後の復元、JSON/CSV書出し、最新10件を残す／全削除を確認する。書出し先のファイルに映像・画像が含まれないことを確認する。
7. 手動設定を変え初期値復元を押す。従来のHSV許容幅や感度が変わらないことを確認する。ストレージ保存拒否時も操作と書出しを確認する。
8. 部位認識と背景ぼかしを5分以上使用し、Safari停止・熱・メモリ増加を観察する。FPSは実測値を記録し、PCの値を転記しない。CPU使用率・電池消費率はアプリから取得していない。

認識結果は実験用途です。未学習物体の検出や実世界の安全判断には使用しません。
