# iPhone Safari 実機確認手順

この手順は未実施です。PCの模擬カメラ検証と区別してください。

## v0.2.0 COLOR & MOTION LABの追加確認

HTTPS配信を準備して親メニューの「カメラ認識実験室」を開いてから実施します。

1. 物体認識で起動・前後切替・停止・再起動と、名前・信頼度・閾値・件数を確認。
2. カメラ動作中に色認識へ切り替え、カメラ使用表示と映像が途切れないことを確認。赤・青などの物体をタップしてHSV許容幅を変え、同色の複数領域、中心、面積、ID・軌跡、ノイズ除外を確認。
3. 通常・BEFORE・AFTER・左右比較を切り替え、同じ物体と枠の位置が一致することを確認。前面カメラでタップした色と領域が一致することも確認。AFTERは結果だけで、色選択は表示範囲内の元映像位置に対応する。
4. iPhoneを固定し動体検出へ切り替え、「背景基準を再取得」を押す。物を動かし、強調領域・矢印・表示px/s・軌跡を確認。物を約1.2秒静止させ、検出データの「静止」を確認。カメラ移動と照明変化による誤検出も記録。
5. 輪郭／図形認識へ切り替え、白黒や鮮明な色の円・三角形・四角形・直線、凹形、微小ノイズで確認。中心・近似面積・傾き、円の傾き「—」、未分類の輪郭の表示を確認。
6. 感度、HSV許容幅、比較表示、モードを変更して停止・ページ再読込。設定が復元され、カメラは勝手に起動しないことを確認。
7. 素早いモード切替、認識ON/OFF、物体認識への復帰、タブ移動と復帰を確認。認識エラー時も映像が継続し、「認識を再試行」や別モードで復旧できることを確認。
8. 各モード5分程度で映像FPS・描画FPS・認識FPS・処理ms、発熱、バッテリーを記録。PCの数値で補わない。Safari実機のWorker／互換方式を診断から転記。

スマートフォンのカメラ自体が動く条件や物理速度計測は今回の対象外です。日本語キーボード不要の選択・スライダー操作ですが、ダブルタップ拡大抑制と画面回転は実機で確認してください。

## ローカルHTTPSの準備（公開不要）

1. `npm ci`、`npm run assets`、`npm run build` をPCで実行する。
2. PCの `dist/` を静的サーバーで配信する。Caddy等を使い、PCのLAN IPまたはローカルホスト名に対してHTTPSを構成する。証明書にはアクセス先IP/ホスト名のSANが必要。
3. 信頼できるローカルCAで発行した証明書を使用する。iPhoneにCA証明書をインストールし、「設定 → 一般 → 情報 → 証明書信頼設定」で信頼する。秘密鍵はiPhoneへコピーしない。証明書警告を無視しただけの接続では確認しない。
4. PCとiPhoneを同一LANへ接続し、PCのファイアウォールで使用ポートを許可する。Safariで `https://<PCのLAN IPまたはホスト名>:<ポート>/` を開く。
5. 診断情報の「安全な接続: true」「カメラAPI: true」を確認する。HTTPのLAN URLやiPhone上のlocalhostはPCへ接続する方法にはならない。

サーバーや証明書は本プロジェクトには自動導入しません。将来のGitHub Pages利用時は配信URLのHTTPSを利用できますが、今回push・公開はしていません。

## 確認項目

- [ ] 機種、iOS/Safari版、日時、バッテリー状態、画面向き、温度を記録
- [ ] 起動ボタンを押す前はカメラが動作しない
- [ ] 起動→許可→映像→モデル読込→認識枠・名前・信頼度
- [ ] 拒否→エラー→サイトのカメラ設定を許可→再試行
- [ ] 読込中のキャンセル、許可待ち中のキャンセル→後から許可してもカメラが残らない
- [ ] 人・カップ・ボトル等で位置と日本語表示、複数物体の件数
- [ ] 前面／背面切替で映像が切り替わり、鏡像でも枠が一致する
- [ ] 縦／横回転、Safariアドレスバー伸縮で枠と映像の座標が一致する
- [ ] 閾値変更で低信頼度結果が除外され、件数も変わる
- [ ] 認識OFFで枠・件数・認識FPS・推論msが消え、映像は継続
- [ ] 読込中の認識ON/OFFでもエラーや二重推論が起きない
- [ ] 解析長辺／認識間隔変更で動作を継続
- [ ] 診断の実行方式を記録。Worker非対応時に互換方式で動作する
- [ ] 停止でiOSのカメラ使用表示が消える。再起動できる
- [ ] 他タブ移動、ホーム画面、画面ロックで停止し、復帰後に手動再起動できる
- [ ] 5分連続動作でFPS、推論ms、発熱、電池消費、操作応答を記録
- [ ] SafariのWebインスペクタで通信先が同じサイトのみ、フレーム送信がないことを確認
- [ ] モデルのURLを一時的に404にしたテスト配信で案内・再試行を確認
- [ ] ブラウザ幅から横はみ出しせず、下部操作を押せる。不要なダブルタップ拡大がない

認識結果は実験用途です。未学習物体の検出や実世界の安全判断には使用しません。
