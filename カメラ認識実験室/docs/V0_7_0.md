# v0.7.0 — AR CARD LAB

## 再利用した基盤

既存TextMarkerModeのclassic Worker・js-aruco2 2.0.0・ARUCO_MIP_36h12・複数マーカー検出をそのまま利用します。新たなライブラリ・モデル・大型素材はありません。既存warpをprojection.tsへ移動し、位置追従合成とカードで共有しました。共通カメラ・ModeSession・単一inFlight・自動負荷調整・前面鏡像・比較表示・結果TTLを維持します。

## カード

対応表は `src/textmarker/cards.ts` で管理します。

| ID | カード | 反応する組み合わせ |
| --- | --- | --- |
| 7 | ロボット | バッテリーで充電、スライムへ手を振る |
| 11 | スライム | バッテリーでふくらんで跳ねる、ロボットへ手を振る |
| 19 | バッテリー | ロボットとスライムを応援 |

`ar-cards.html` は既存markerSVGと同じ辞書から600×720pxの名前付きカードPNGをメモリ上で生成します。600px角のマーカーをカード内へ置き、白い余白・黒枠・6×6コードを保持。カード名・ID・遊び方はコードに重ねません。3枚のA4印刷レイアウトは各56mm幅、マーカーの黒い部分は約44.8mm角です。端末上では1枚の拡大表示と個別PNG保存も可能です。保存は利用者の操作時だけです。

絵は `card-art.ts` の自作Canvas図形です。PNGや外部画像の追加取得は不要。カードの四隅に既存12×12メッシュで射影合成します。未登録IDは診断だけに残し、絵・反応の対象にしません。通常の件数は合成対象（上限8枚）です。

## ペア判定

1. 単一EngineResultに入った2枚だけを比較します。`now < expiresAt`、新しいframeIdかつ撮影時刻が前回より新しい場合だけ1回更新。描画からupdateを呼びません。過去フレームの片方を保存して補完しません。
2. 元画像の幅・高さを掛けてピクセルへ戻し、各四角形の4辺長の平均を見かけサイズとします。中心間距離を、2枚の見かけサイズの平均で割ります。縦横を個別に0〜1にした空間の距離を直接使わず、縦画面でも比率を保ちます。
3. 初期値は **近い≤1.8、離れた≥2.5、各3回の有効検出**。近い3回で1回発火し、離れた3回までロック。中間値は確認回数をリセットします。2枚を識別しやすい隙間を残して反応できる近接域と、手ぶれで解除されにくい離隔域を設けた実験用初期値です。実機精度に基づく最適値ではありません。
4. 検出間隔が1200msを超える場合、片方が欠落、同IDが複数で対応が曖昧な場合は連続確認をリセットします。**発火済みロックは欠落・TTL切れでは解除しません**。十分な離隔の3検出だけが再発火を許可します。カメラ停止・実験変更では履歴ごとクリアします。
5. ペアキーはカード名をソートして作り、左右・検出配列順序に依存しません。最大3ペアの状態だけを保持します。3枚同時なら有効な各ペアを判定し、同じカードに複数演出がある場合は状態リストの後方の演出を優先します。

## 演出とライフサイクル

充電・ジャンプ・手振りは1800ms。共通描画ループから最大30回/秒で小さなテクスチャだけを更新し、検出頻度は増やしません。最新の有効な検出四隅で演出を描き直します。比較表示は既存と同じくBEFOREがライブ、AFTERが解析フレーム＋合成です。検出間の位置を推測補間していません。

欠落時はその対象を描かず、ペアの演出も解除。TTL切れで元映像へ戻し、ロックだけ保持。停止・認識OFF・モード変更はWorker・結果・演出・履歴を解除します。前面反転は完成した合成を含め既存描画側で行います。正確な3D姿勢・物理距離・接触・マーカーなしARは扱いません。

## 保存・配布・制約

カード実験の選択は既存設定キーへ互換追加し、カード入力はカメラ連続へ制限。既存のOCR・コード・画像照合・マーカー・合成は維持します。画像・映像・カード反応履歴を自動で永続保存しません。既存実験記録は許可済み集計メタデータだけを扱います。依存のライセンスとモデル識別情報は変更していません。Viteの複数HTML入力にカード準備ページを追加し、リポジトリ配下の相対URLでも配信できます。

小さすぎるカード・遮蔽・反射・ブレ・極端な傾きで認識は失敗します。既存検出器が内部の模様などを別IDと推定する例もあり、未登録IDは無視します。誤って登録IDと認識する可能性まで除去するものではありません。処理間隔が大きい環境では1200msの確認窓を満たせず、反応しない場合があります。

iPhone実機の精度・性能、実物印刷・プリンターの余白・長時間安定性は未確認です。PC合成画像テストの成功を実機確認と混同しないでください。手順はIPHONE_CHECKLIST.mdを参照してください。
